Create a new Strava route by uploading a GPX file directly from your computer, then adjust waypoints and route preferences before saving it to My Routes. Written by Marie Updated over 3 weeks ago You can create a Strava route from a GPX file by selecting Dashboard from the top navigation menu on the Strava website, then My Routes > Create New Route . Click the upload button and choose the GPX file you'd like to use to create a route. Once the file has been uploaded, you can adjust the waypoints on the map or edit your route preferences as necessary. Select Save once you've finished.
